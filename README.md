# GridCraft PR review illustrations

Original GridCraft UI screenshots captured with synthetic workbooks on Fedora through an offscreen egui/wgpu harness. Bryan reviewed and approved these images on 2026-11-05. This evidence-only branch is kept separate from product PRs.

These are captures of earlier recorded sources, not new screenshots of the updated main-based branches. `provenance.json` records each source commit, uncommitted diff hash, capture binary hash, timestamp, dimensions and image checksum. The images illustrate the relevant workflows; they do not establish test results for a later revision. No Excel screenshots, Office assets, workbook files or font files are included.
